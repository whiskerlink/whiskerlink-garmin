# How to use WhiskerLink

Power on the Testo 549i, then start WhiskerLink on the watch.

The app will scan, connect, complete the Testo handshake, and begin showing live pressure.

## Navigation

WhiskerLink has two main pages:

```text
Refrigerant
    ↑
    ↓
549i
```

### 549i page

- **UP**: go to Refrigerant
- **SELECT**: open probe actions
  - Zero
  - Block *(not implemented)*
  - Device Info

### Refrigerant page

- **DOWN**: return to the probe
- **SELECT**: choose a refrigerant

The selected refrigerant is applied immediately to the current pressure reading.

## Startup display

Before live data arrives, the probe page shows connection status as bottom-up scrollback. Once streaming begins, it becomes the normal pressure and saturation display.
